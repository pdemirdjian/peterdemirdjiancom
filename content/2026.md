## Claude Code through Amazon Bedrock

**Taking AI coding from individual use to shared infrastructure.**

I led organization-wide Claude Code enablement through Amazon Bedrock. Instead of individual accounts, engineers got one shared access model:

* Per-user inference profiles, managed in Terraform.
* Per-user usage-cost visibility in CloudZero.
* 287 engineers onboarded by early April.

The work didn’t stop at launch. I own organization-wide Bedrock model enablement as an ongoing platform responsibility: in September I had a newly released model enabled for the whole organization three days after its public launch, once a colleague had completed the model review.

## Mauve: the platform behind agentic development

**Building the infrastructure behind agentic development.**

On the AIDLC team I help build the platform and delivery infrastructure for Mauve, CarGurus’ agentic development platform:

* Production-environment planning.
* Terraform-managed delivery paths.
* An approval-gated CircleCI production deployment lane backed by AWS CodeBuild, with its own roles and an explicit approval gate.

The production cutover is still in progress.

## AWS self-service and infrastructure modernization

**Making cloud infrastructure easier for engineering teams to use.**

I helped advance AWS self-service at CarGurus through HCP Terraform, approved infrastructure patterns and built-in guardrails, so teams have a clearer path to provisioning and running their own cloud resources. The platform team’s reported results:

* About 80% less active provisioning effort: roughly one day of hands-on work instead of five.
* Development resources managed through the platform grew from about 92 to 197 between mid-March and mid-May.
* Production resources grew from about 73 to 204 over the same period.
* Claude Code provisioning scenarios succeeded across S3, Lambda, ElastiCache and RDS.

Alongside it, I’m moving AWS infrastructure from CDK to HCP Terraform and connecting HCP Terraform to GitHub Enterprise Server.

## Shift-left Terraform guardrails

**Bringing infrastructure guardrails into the coding workflow.**

I presented a design at CarGurus’ Science Fair for Semgrep checks that run as Claude Code writes Terraform. IAM-policy feedback arrives while the code is being written, instead of as a late policy failure that ends in a manual override.

The production guardrails rollout was led by a teammate, with support from Cloud Enablement and InfoSec. It has eliminated 262 soft-mandatory policy override requests.

## Carport: tools that coding agents can use reliably

**Making an internal product usable by people and coding agents.**

Carport is CarGurus’ internal static-site platform. I shipped its agent-friendly CLI:

* Machine-readable results and errors.
* Stable exit codes and clear authentication states.
* Command help, plus an embedded Claude Code skill guide that teaches an agent how to use the CLI.
* Collaborator add and remove commands.

The broader team built the portal, hosting and authentication.
