## 2026: From AI Enablement to Agentic Development

<div class="about-text">
<p>2026 marked a shift from enabling AI-assisted coding to building agentic development platforms. I won CarGurus’ Pioneering Award for getting the organization onto Claude Code through Amazon Bedrock. That work led to my selection for the AIDLC tiger team, where I help build the systems behind agentic software development.</p>
</div>

* **Pioneering Award:** for enabling organization-wide adoption of Claude Code through Amazon Bedrock.
* **Claude Code through Bedrock:** a shared access model with Terraform-managed per-user inference profiles and per-user cost visibility; 287 engineers onboarded by April.
* **AIDLC tiger team:** selected in May to build agentic development across planning, testing and deployment.
* **Mauve:** delivery infrastructure for CarGurus’ agentic development platform, including an approval-gated production deployment lane.
* **AWS self-service:** a platform that cut active provisioning effort by about 80% (team result).
* **Shift-left guardrails:** originated Semgrep IAM checks that run as Claude Code writes Terraform, built with a teammate.
* **Carport:** an agent-friendly CLI with machine-readable errors, stable exit codes and an embedded Claude Code skill guide.
